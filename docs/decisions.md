## 2026-10-01 模组改名为 Molin

**背景：** 原工程基于 RitsuLib 官方模板，内部 ID、命名空间、资源路径全部沿用 `Sts2Mod`。项目确定正式名称后，需要彻底改名，避免后期改动成本更高。

**结论：** 同意

**理由：** 早期改成本最低；后期本地化 key、资源路径、类名遍布全仓库，改动风险大。

**执行人：** hwjsldgj

**影响范围：**
- 顶层文件夹：`Sts2Mod/` → `Molin/`，`Sts2ModCode/` → `MolinCode/`
- 工程文件：`Sts2Mod.csproj` / `.sln` / `.json` → `Molin.*`
- 命名空间：`Sts2Mod` → `Molin`
- 类名前缀：`Sts2Mod*` → `Molin*`
- 本地化 key 前缀：`STS2_MOD_*` → `MOLIN_*`
- 资源路径：`res://Sts2Mod/` → `res://Molin/`
